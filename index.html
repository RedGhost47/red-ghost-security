✦ CASE STUDIES

Selected findings

Real vulnerabilities identified across recent engagements. Every finding includes a verified PoC with measured economic impact.

🔴 CRITICAL

Uniswap V2 Spot Price Oracle

Generalized · All EVM Chains · Public

getReserves() used directly without TWAP protection enables single-block flash loan manipulation.

Impact: 10.57% price deviation with 500k USDC flash loan (Ethereum block 25,051,620).
Fix: TWAP accumulator ≥30min · Chainlink validation · Circuit breakers.
🟠 HIGH

AladdinDAO / CLever

Yield/Vault · Non-Ethereum

Manual price feed without oracle validation. Flash loan manipulates quote asset → drain vault.

Vector: Uniswap V2 spot price as primary oracle. No TWAP implemented despite secure version existing in repo.
🟠 HIGH

Exactly Protocol

Lending · Optimism

latestAnswer() returns stale prices. No staleness threshold — outdated price can persist for hours.

Impact: Incorrect liquidations, undercollateralized borrowing.
Fix: Add updatedAt validation with max staleness tolerance.
🟠 HIGH

BiFi Protocol

Lending · Multi-Chain

Cross-chain oracle bridge vulnerability. Price inconsistencies between source and destination chains.

Attack: Flash loan on source chain → exploit stale bridged price on destination.
🟠 HIGH

Wildcat Protocol

Lending · Ethereum

Permissionless market factory lacks rate validation. Predatory lending terms deployable by anyone.

Risk: Unchecked constructor parameters enable malicious market creation.
